# Testing Strategy

## Test Levels

- Unit: services, calculations  
- Integration: API \+ DB  
- E2E: critical user flows

## Required for Every Change

- Test for the happy path  
- Test for at least one failure case

## Tooling

- Pytest  
- Playwright  
- Coverage enforced in CI

## Definition of Done

- Tests pass  
- New behavior covered  
- No regressions
