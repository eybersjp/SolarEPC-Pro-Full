# Antigravity Workflow

## Command Vocabulary

/plan   → analyze & design /build  → implement code /verify → test & validate /triage → diagnose broken code

## Agent Obligations

- Always restate intent  
- Always identify root cause  
- Always explain before fixing  
- Always include tests  
- Always include verification steps

## Fix Output Format

1. Intent Summary  
2. Issues (Correctness, Security, Data, Perf, DX)  
3. Fix Plan  
4. Patch  
5. Tests  
6. Verify Commands  
7. Rollback Plan
